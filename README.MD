# Fernando 64

Fernando 64 is an IDE, a small language and an emulator for making
Commodore 64 games, apps and demos. It is for ten-year-olds and for adults.

You write a program in Fernando 64, or make a game without writing any code
in the Designer, drop your pictures and tunes into the asset tabs, and press
Run. The IDE compiles the program to 6510 machine code, runs it in its own
cycle-exact C64, and exports a .prg, a .d64, a cartridge or a web page.

The source is being prepared for release and will appear here.
